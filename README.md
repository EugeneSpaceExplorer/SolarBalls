# SolarBalls Interactive Universe HQ

## Main features
- Shared cosmic visual design across every page.
- Dedicated pages for all 8 planets.
- Dedicated pages for the Sun, Pluto, the Moon, and 10 featured moons.
- Clicking a planet or moon card always opens its own description page.
- Searchable planet and moon explorers.
- Universe Quiz with a 60-question bank and 10 randomized questions per round.
- Local Top Scores leaderboard using browser localStorage.
- Responsive layout for desktop and mobile.

## GitHub Pages
1. Upload every file in this folder to your repository.
2. Make sure `index.html` is at the repository root.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save.

This is an unofficial fan project. It is not affiliated with the creators of SolarBalls.
